# Introdução {.unnumbered}
### Por Jon Trigueiro {.unnumbered}

## Para quem é este manual {.unnumbered}

Olá! Esse manual é para o jovem iniciante no rampo da programação. Fiz inicialmente para o meu amigo Igor, mas se isto for válido para ti, fique à vontade. Isto é fruto da minha curadoria, utilizando IA, mas voltado para o aprendizado. Irei validar todas as documentações propostas nesse texto de modo a criar um documento que sirva de documentação para as iniciativas. Considere isso como uma forma de usar os poderes das LLM à favor do ensino, e não tomar o lugar dele, coisa que sou completamente contra.

## Por que um "toolbox" e não um curso? {.unnumbered}

Imagine uma caixa de ferramentas. Para desempenhar bem uma atividade, voce precisará de ferramentas, não é? no T.I. é a mesma coisa: você, para executar uma ação, precisará conhecer que há de disponível para ser utilizado. Este documento é apenas o início do seu repertório tecnológico para o desenvolvimento de projetos. Farei uma adição modular e incremental desse projeto à partir das necessidades e desafios que eu disponibilizarei.

O mais importante, que essa ferramenta não pretende te entregar é o melhor caminho para se fazer as coisas. A intenção dele é focar justamente nas ferramentas de maneira individualizada em modular para servir como uma compilação de tutoriais e ferramentas que voce pode fazer uso na sua rotina de aprendizado. Considere como um ponto de partida, uma preparação para que voce possa alçar voos maiores, entrar na documentação oficial e ou coletar material complementar. Isto garante que este conteúdo não substitua o original, muito menos dite uma forma de aprendizado: isto definitivamente não é o objetivo.

## Como usar este livro {.unnumbered}

Conte com ele como se voce precisasse de um guia, ou usasse como aqueles cds de jogos demo que vendia na banca de revista. (é o novo! haha) A magia daquilo era justamente entender os demos dos jogos e se sentir curioso para ver o jogo completo. Tente aceitar esse manual como isto. Também, se voce se sentir motivado, pode experimentar fazer os exercícios propostos e ler as documentações adicionais.

## Como este livro é construído {.unnumbered}

Ele será mantido no repositório e todo a sua estrutura será feita de modo a ser construída incrementalmente. Não acho que eu seja o real criador da obra (dado que o Claude fará o trabalho sujo de construir as coisas, mas ao menos terá minha curadoria de modo a ter um conteúdo focado nos objetivos macro que eu quero propor para atender o objetivo básico de ensinar a pessoa a programar.

## Importante {.unnumbered}

A missão é oferecer ferramentas. A forma de se fazer, de pensar em algorítmo, é com você. Ensinar algorítmo é uma das coisas mais difíceis de se ensinar. Acredito que a experiência, associado à exposição a uma quantidade de problemas variados e os aprendizados disso, é o que garante que o desenvolvedor exerça sua principal qualidade: resolver problemas.

Possivelmente, durante as lições, eu adicione algumas notas ou coisas que eu ache jogo adicionar.

Ande com este manual para todos os cantos possíveis. Com tempo livre, faça uma leitura "culposa" (sem a intenção de aprender algo [rs]) e vá se tornando confortável com a linguagem. Quando quiser trabalhar com mais afinco, você volta e faz uma leitura mais focada. 

Não abordarei a utilização de LLMs para criar prompts, nem nada do tipo. A idéia é fazer com que voce meta a mão na massa e use os conhecimentos como ponto de partida. 

Aproveite!
